# Change Log

All notable changes to the *Revenant* framework will be documented in this file.

## [1.0.1]
- Added the `debugOutput` option for better integration with DebugView.
- Added `"not"` gate mode for `condition` options with single values and changed the `"xor"` implementation to a proper multi-input xor cascade.

## [1.0.0]
- First public release.
